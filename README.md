# Jump & Dodge

A responsive HTML5 canvas game built with vanilla HTML, CSS and JavaScript.

## How to play
- Press **Space** or **Arrow Up** to jump.
- On mobile, tap the game.
- Avoid the obstacles and beat your best score.
- Press **R** or use **Play Again** after a collision.

## GitHub Pages
This project is designed to work directly from the repository root with GitHub Pages.
